# Robridge Watersports website

A single-page Robridge Watersports brand site with:
- Full-screen background video hero
- Project navigation
- Project cards linking to individual products
- Impact section
- Journal/articles section
- Contact CTA
- Responsive mobile navigation

## Add the hero video
Put your watersports video in this folder and name it:

hero.mp4

Optional: add a still image named `hero-poster.jpg`.

## Current project links
CrewFinder is linked to:
https://crew-finder-roan.vercel.app/

Update the other project URLs in `index.html` as the projects go live.

## Run locally
Open `index.html` in a browser, or deploy the folder to Vercel/Netlify/GitHub Pages.
